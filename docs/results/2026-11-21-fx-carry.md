# FX carry — 2026-11-21

Same 10 pairs. Carry = base short rate − quote short rate (OECD 3-month interbank, FRED),
lagged 2 months so only published data is used. Returns include daily swap accrual
(total-return index). Long the 3 highest-carry pairs, short the 3 lowest, risk-scaled,
monthly rebalance, gross ≤ 3x. Costs: 1.5 bps/side + 1%/yr financing markup on gross.

**Verdict: rejected for live capital.** G10 carry has earned roughly nothing since 2008 once
crashes are included; the swap markup a retail CFD broker charges removes what's left.
